# tree-sitter-lua-spm

Swift Package Manager wrapper for the [tree-sitter-lua](https://github.com/tree-sitter-grammars/tree-sitter-lua) grammar.

## Usage

Add this package to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/burin-labs/tree-sitter-lua-spm.git", from: "0.2.0")
]
```

Then add `TreeSitterLua` as a dependency of your target.
